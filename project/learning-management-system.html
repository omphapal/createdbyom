Learning Management System (LMS)

A full-stack Learning Management System uniting learning content, assignments, attendance, assessments, analytics, and placement workflows behind a centralized API gateway.

Discuss a Similar Project

Project links & screenshots can be added in site-config.js and project/learning-management-system.html once hosted publicly.

Problem It Solves

Training institutes and cohorts often juggle disconnected spreadsheets for attendance, assignments, assessments, and placement records.

Solution & Architecture

Designed modular Java and Spring Boot services behind a centralized API gateway with React views, Kafka event streams, Redis caching, and MySQL persistence.

Key Features

  • Centralized API gateway routing across modular services
  • Course learning, assignment, and assessment modules
  • Attendance tracking and student progress analytics
  • Dedicated placement module for cohort readiness
